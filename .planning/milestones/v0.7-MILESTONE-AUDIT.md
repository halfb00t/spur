### Integration warnings (non-blocking)

- **W1. The caches carry no tables fingerprint.**
  - The solid `lru_cache` and `_EXPORTS` are keyed on params only.
  - This is safe today because the tables are fixed per process (D-13).
  - Only tests guard it, not a key. A future runtime `install()` could serve a stale solid.
- **W2. The download name ignores the tables state.** The name is the same with and without
  tables (by design, L49). Two saved files, one max-material and one nominal, cannot be told
  apart by name.
- **W3. The tables file is read once.** If the file is deleted or corrupted after startup, it is
  not re-read. Recovery needs a restart, which is consistent with D-13.
