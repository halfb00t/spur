Contents:
- `spline_start(pr: Profile, fillet: float) -> float`: the radius where `model._outline`'s involute spline begins. Copy the three r_line/r0 lines at model.py 123-125 exactly. The docstring says it mirrors them, and that 10-02 moves them into `spur.calc`, after which this module imports that function instead.
- `tip_arcs(solid: cq.Shape, ra: float, face_width: float) -> list[cq.Edge]`: the CIRCLE edges whose `radius()` is within `model.TOL` of `ra` and whose `startPoint()` and `endPoint()` both have z within TOL of 0 or of `face_width`. This is the selector 10-02 ships. The docstring gives the reason for the z test: the moved arcs at z = c and face_width - c.
- `chamfered(solid: cq.Solid, c: float, edges: list[cq.Edge]) -> tuple[cq.Solid | None, str]`: calls `solid.chamfer(c, None, edges)`. It returns the single valid solid and an empty string. Otherwise it returns None and the reason: `solids=N` (not exactly one solid), `invalid`, or the exception class name. Catch `Exception`, the same breadth as `model._build_checked`'s catch-all, with a comment saying so.
- `@dataclass(frozen=True) class CostRow`:
  - Fields: `label: str`, `teeth: int`, `arcs: int`, `per_face: tuple[int, int]`, `bare_s`, `chamfer_s`, `stl_s`, `step_s`, `d_faces: int`, `d_cone: int`, `d_edges: int`, `d_volume: float`, `bbox_moved: float`, `why: str`.
  - Property `request_s`: `bare_s + chamfer_s + max(stl_s, step_s)`. This is the cold request SPUR_BUILD_TIMEOUT wraps (Timing.worst_request's reasoning).
  - `ok()`: returns True when `why` is empty, `arcs == 2 * teeth`, `per_face == (teeth, teeth)`, `d_faces == d_cone == 2 * teeth`, `d_edges == 6 * teeth`, `d_volume < 0` and `bbox_moved < TOL`.
  - `line()`: one Markdown table row with every field, times to 2 dp, `request_s` included.
- `cost_row(kw: dict[str, object], c: float) -> CostRow`:
  - The label is the set's own `key=value` pairs in dict order followed by `c=<c>`, for example `teeth=200 module=10 c=3.375` (build_time.load_sweep's label shape). Every COST_SETS key dict starts with `teeth`, so every cost row starts with `| teeth=`.
  - `GearParams.model_validate(kw)`, then time `model._build_checked(p)`, then take `tip_arcs`.
  - Time the chamfer. On success, time the fine STL and the STEP of the chamfered solid in a `tempfile.TemporaryDirectory`, using `model._write_export`'s own calls with `model.TESSELLATION["fine"]`.
  - `d_cone` is the CONE count in `collections.Counter(f.geomType() for f in ...Faces())`, after minus before.
  - `bbox_moved` is the max absolute change over the six BoundingBox corners (xmin..zmax).
  - A failed chamfer gives a row with its `why` and zero deltas.
- `COST_SETS`: a list of (kw, (c, ...)) pairs:
  - `{"teeth": 19}`, `{"teeth": 40}`, `{"teeth": 200}` at the default module with c (0.4, 1.75);

  - If `hi` builds, return `(hi, float("inf"), pred, "builds at the top")`.

## Flagged Assumptions

- **A1 (the module-0.2 rows need backlash below the default).** CONTEXT's `<specifics>` placed the 200-tooth module-0.2 tip at about 0.12 mm "at the default backlash". On the pinned code the default backlash (0.1 mm) makes that gear a 422 ("Teeth come to a point (tip 0.02 mm)"). The 0.12 mm figure is the backlash-0 tip. The spike and D-06's ninth sweep row use backlash 0.07, the finest tip check() allows (0.054 mm; 0.08 is refused). At 19 and 40 teeth module 0.2 needs backlash 0 and no bore. This is a sweep-row exactness choice CONTEXT left to the planner, not a changed decision.
- **A2 (the probe is committed).** CONTEXT allowed a throwaway. The script is committed so the D-04 boundary and the D-12 deltas stay reproducible (bench/README.md "The one rule"). It is not wired into the Makefile: it is a one-off measurement recorded with its exact command.
