Contents:
- `BUDGET_S = 7.5`: a quarter of the 30 s `SPUR_BUILD_TIMEOUT` (D-11; the comment names the 14.87 s tip-chamfer row it leaves room beside).
- `whole_cells(cell: float, wall: float, inner: float, outer: float) -> tuple[tuple[float, float], ...]` per D-07, D-08, D-09: an axis-centred lattice, pitch `cell + wall`, row spacing `pitch * sqrt(3) / 2`, centres `x = pitch * (a + b / 2)`, `y = pitch * b * sqrt(3) / 2`; a centre is kept when `inner + cell / sqrt(3) <= hypot(x, y) <= outer - cell / sqrt(3)` (inclusive; the corner reach is the circumradius, CONTEXT's exact test). Return an empty tuple when the band is empty. Iterate `b` ascending, then `a` ascending, so the same arguments return the same tuple every time. Bound the candidate ranges from `outer` so no candidate outside the square |x|, |y| <= outer is visited. Docstring: flats on +-X and vertices on +-Y, the hex bore's convention (`model._cut_bore`); the origin cell lies inside the bore and is never cut; 11-05 moves this function into `spur.calc` unchanged, after which this module imports it.
- `cell_count_floor(cell: float, wall: float, inner: float, outer: float) -> float`: a guaranteed lower bound on `len(whole_cells(...))`, `pi * (hi2 ** 2 - lo2 ** 2) / (sqrt(3) / 2 * pitch ** 2)` with `pitch = cell + wall`, `lo2 = inner + cell / sqrt(3) + pitch / sqrt(3)`, `hi2 = outer - cell / sqrt(3) - pitch / sqrt(3)`, and 0.0 when `hi2 <= lo2`. Docstring: D-13's "area estimate", taken as a floor — the centre band eroded by the pitch hexagon's circumradius, over the pitch hexagon's area; every point of the eroded band lies in the Voronoi cell of a lattice point inside the band, so the count is at least this (planning checked 1920 sets, 0 violations).
- `cells_within(cap: int, cell: float, wall: float, inner: float, outer: float) -> tuple[float, tuple[tuple[float, float], ...]]` per D-13: for k = 0, 1, 2, … take `s = round(cell + 0.05 * k, 3)`; when `cell_count_floor(s, …)` exceeds `cap`, skip without enumerating; otherwise enumerate `whole_cells(s, …)` and return `(s, cells)` if `len(cells) <= cap`. Docstring: a skipped size can never have fitted, so the first size returned is exactly D-13's "stepped up by 0.05 mm from the request until the exact whole-cell count is <= the cap", and the exact enumeration never runs for millions of cells. `cell` must round to a positive size (11-05's check() refuses one that does not); 11-05 moves this and both functions above into `spur.calc` unchanged.
- `hex_prisms(cell: float, face_width: float, centres) -> list[cq.Solid]`: one prototype from `cq.Workplane("XY").polygon(6, cell, circumscribed=True).extrude(face_width).val()` narrowed with `isinstance(..., cq.Solid)`, then `proto.translate(cq.Vector(x, y, 0))` per centre.
- `cut_with(solid: cq.Solid, prisms: list[cq.Solid], spelling: str) -> cq.Shape`: `"star"` is `solid.cut(*prisms)`, `"compound"` is `solid.cut(cq.Compound.makeCompound(prisms))`, `"fuse"` is `solid.cut(prisms[0].fuse(*prisms[1:]))`.
- `@dataclass(frozen=True) class CostRow`: `label: str`, `target: int`, `cell: float`, `cells: int`, `bare_s`, `cut_s`, `stl_s`, `step_s`, `d_faces: int`, `why: str`; property `request_s` = `bare_s + cut_s + max(stl_s, step_s)` (Timing.worst_request's reasoning); `ok()` is `why == ""` and `cells <= target`; `line()` renders one Markdown row, times to 2 dp.

Time `model._build_checked(p)`, time `cut_with(...)`; the result must be exactly one valid solid, else `why` is `solids=N`, `invalid` or the exception class name (catch `Exception`, `_build_checked`'s breadth, with a comment saying so); on success time a fine STL and a STEP of it in a `tempfile.TemporaryDirectory`, using `model._write_export`'s own calls with `model.TESSELLATION["fine"]`; `d_faces` is faces after minus faces before. ## Flagged Assumptions

- **A1 (the cap is the row's cell count, not its target).** D-12 says "the largest count whose sweep
  row ... reads <= 7.5 s". Raise-to-fit lands at or under a target (planning: target 100 cut 96 cells),
  so the plan takes the cells the row actually cut. A target-valued cap would let another gear cut up to
  four more cells than were measured.
- **A2 (a module-1.75 confirmation).** D-11 names module 10 as the heaviest gear because its web is the
  largest. The planning probe read module 1.75 heavier at the same count (8.4 s against 7.6 s at 150
  cells, under load): the smaller gear's cells cross the recess groove and its fillets more often. The
  spike records one confirmation row and fails its verdict if that row overruns, so a human, not the
  planner, decides whether D-11's configuration still sets the cap.
- **A3 (the 50-cell gate).** D-24 asks for a checkpoint "if even a modest count overruns"; the plan
  fixes "modest" at 50 cells, about half of the roughly 100 cells the planning probe measured inside
  budget. A cap under that means the planning numbers were wrong enough for a human to look again.
