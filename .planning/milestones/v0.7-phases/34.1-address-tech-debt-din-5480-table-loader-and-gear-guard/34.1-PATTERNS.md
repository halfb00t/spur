**Existing rule shape** (`problems()`, lines 280-287). Sentences name a location and never a value. The `A_s` cap goes in the `for dev in t.deviations` loop next to the `UM_LIMIT` belt (D-01, D-04):
```python

            found.append(f"{at}: a micrometre field is beyond {UM_LIMIT}")
    for dev in t.deviations:
        if any(abs(v) > UM_LIMIT for v in dev.a_s_um):
            found.append(f"deviations {dev.letter!r} (page 24): a micrometre field is beyond "
```

- `UM_LIMIT = 1000` is the module constant at line 38. Put the new `k` constant beside it with a comment carrying the reasoning and no table value (D-01; the human sets `k`).
- `m` for a cell: the largest `module_max_mm` of the column row (`ColumnRow.column == index+1`) that the cell sits in. Cell `i` of `dev.a_s_um` is column `i+1`. Several `ColumnRow` can share a column number, so take the max over rows with `col.column == i + 1`. If a column has no row, skip the cell. The `n_selecting` check already reports that.
- The loop `for col in t.columns` at ~315 shows how `col.column`, `col.module_max_mm` and `_column_key(col)` are used.
- The message names letter and column, not the value, for example `f"deviations {dev.letter!r} (page 24): column {i + 1} A_s is beyond the module cap"`.

**Table 7 all-or-none rule (D-05)** goes just before or after the provenance loop (lines 266-270). The four lists are already iterated there:

Add `present = [bool(rows) for _, rows in ...]` and `if any(present) and not all(present): found.append("Table 7 is partly present: ... lists the empty ones")`. Name the kinds, not values. `test_a_document_of_empty_row_tuples_loads` (all empty) must still pass.

### `scripts/gear_unchanged.py` (utility, subprocess)

```python
def _git(root: Path, *args: str) -> subprocess.CompletedProcess[bytes]:
    return subprocess.run(
        ["git", "--no-optional-locks", *args],
        cwd=root, capture_output=True, check=False,

```
and in `schema_of`:
```python

        [sys.executable, "-P", "-c", PROBE],
        env={**os.environ, "PYTHONPATH": str(src)},
```

Neither has `timeout=`, `stdin=` or `GIT_TERMINAL_PROMPT`. Pattern to apply (D-07):

Wrap in `try/except subprocess.TimeoutExpired` and raise `SystemExit(f"gear.unchanged: git {' '.join(args)} timed out after {n} s")`. Keep the `gear.unchanged: ` prefix, which `tests/test_gear_unchanged.py::_refused` asserts.
- `schema_of`: add `timeout=PROBE_TIMEOUT_S` (longer, measured on this host, recorded in RESULTS.md) and the same `TimeoutExpired` to `SystemExit` conversion naming the probe and `src`.

New tests, same shape as the existing ones (D-08):
```python
def test_a_lightweight_v0_6_tag_is_refused(tmp_path: Path) -> None:
    work = _work_repo(tmp_path)
    _git(work, "tag", "-d", "v0.6")
    _git(work, "tag", "v0.6")               # lightweight, no -a
    _refused(work, "not an annotated tag")

def test_a_moved_annotated_tag_is_refused(tmp_path: Path) -> None:
    work = _work_repo(tmp_path)
    _git(work, "commit", "-q", "--allow-empty", "-m", "later")
    _git(work, "tag", "-f", "-a", "v0.6", "-m", "moved")
    _refused(work, "...")                    # peels to another sha
```
Unreachable-origin timeout: build on `test_a_missing_tag_with_an_unreachable_origin_fails_naming_the_cause` (136-151), which uses the `lone` repo and `remote add origin`. For a hang rather than a quick refusal, use an origin that blocks, for example a `GIT_ASKPASS`-free `https://` URL to a closed local port or a `file://` path through a FIFO. Monkeypatch the timeout constant to a small value (for example 1 s) and assert both the `SystemExit` text naming the git command and that elapsed time is under the bound plus slack. The planner picks the blocking origin after trying it on the host. Probe timeout: monkeypatch `PROBE_TIMEOUT_S` small and `PROBE` to sleep, or call `schema_of` against a tree whose import blocks.

### SystemExit with a named cause
**Source:** `scripts/gear_unchanged.py`, for example:
```python
raise SystemExit(
    f"gear.unchanged: tag {TAG} is not local and could not be fetched from origin: "
    f"{_stderr(fetched)}"
)
```
Apply to the new tag-kind, tag-sha and timeout failures. Always the `gear.unchanged: ` prefix.

### Comments carry the measurement
**Source:** CODING_VALUES "Vision" and the `problems()` comments ("720 of 720 rows agree inside M1_TOLERANCE"). Apply to `k` (reasoning, no table value) and to both timeouts (the measured bound).

### Behaviour tests, no mocks of internals
CODING_VALUES "Testing". Apply to every test above. The tests assert the refusal sentence, not private calls.
