Layout (Claude's discretion, decided at planning and verified in a scratch tree against this repo's own pyproject config: pytest collects it, `mypy --strict` over `tests` accepts it, ruff passes, the script runs directly): a plain directory `tests/regression/` with NO `__init__.py`. pytest's default prepend import mode puts `tests/regression/` on `sys.path` for the test module, and `python tests/regression/capture.py` puts it at `sys.path[0]` for the script, so both import the siblings as top-level `corpus` and `capture`.
