<objective>
Close the loop: record what was decided, remove the accommodation, and retire the debt.

Two locked decisions are now false in their consequences. L07's memory formula assumed
caches bounded per process; L06's stated consequence — concurrency buys latency, not
throughput — stopped being true the moment there were N independent kernels. This plan
appends the two superseding entries, brings the Docker healthcheck timeout down from the
value that exists only to tolerate the stall this phase removed, and moves the debt file
into `resolved/` in the same commit.

Purpose: `STATE.md` names "L07 needs superseding, not rewriting" as the largest risk in
milestone v0.1. The risk is not that the work is hard — it is that a phase ends with
working code and a decision log still describing the architecture it replaced, at which
point the next agent reads the log and re-litigates a decision that was already remade.
The healthcheck timeout is the same idea in the runtime: CONTEXT.md is explicit that if it
cannot come down, the phase did not land.

Output: L17 and L18, a healthcheck timeout with a measurement behind it, and this
repository's first-ever exercise of its own tech-debt resolution lifecycle.
</objective>
