`docs/architecture/decision_log.md` is append-only by policy: its own header says that to
change an entry you add a new one that supersedes it and say which. CONTEXT.md rates D-18
**one-way** for that reason — a wrong entry is corrected by a further entry, never
rewritten, so whatever goes in stays on the record permanently and every later agent reads
it as settled.

`L20` is about to record, as locked decisions:

- **The library and format (D-01, D-03).** stdlib `logging` with a project-owned JSON
  `Formatter`, one JSON object per line, always — no `SPUR_LOG_FORMAT` knob and no TTY
  detection. `structlog` was rejected (a new pinned package against L12's closure, in an
  image that already carries OpenCascade) and logfmt was rejected (a convention with no
  parser; `jq` is the intended reader).
- **The stream (D-04).** One handler, on stderr, matching the convention `cli.py` already
  sets: stdout is product output, stderr is diagnostics. uvicorn's own records join it
  because `cmd_serve` passes `log_config=None` (D-02).
- **The configuration points (D-05, as corrected by research).** `cli.cmd_serve` **and**
  `app.py`'s `lifespan()`, idempotently. CONTEXT.md originally assumed one call site was
  enough; research disproved that by reading the installed uvicorn's spawn-based
  multiprocessing and by a live reproduction. The second call site is a requirement, not
  defensive belt-and-braces, and `L20` is where that stops being re-litigable.
- **Where records are emitted (D-06).** The parent process only. Workers stay silent by
  decision, with the accepted cost that the kernel's traceback reaches the parent as text
  inside `BuildError`'s message rather than as a class object.
- **The default level and its knob (D-14).** INFO by default, with `SPUR_LOG_LEVEL`
  following the existing `SPUR_*` pattern and falling back to INFO on nonsense.

Before this is written: confirm these are the decisions you want future agents to treat as
settled, and that the reasons attached to them are the reasons you would want cited back
at you. This is the last point at which it is cheap.
