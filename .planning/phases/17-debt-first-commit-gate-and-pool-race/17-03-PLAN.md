## Flagged Assumptions

- **A miss is a plausible outcome, not a harness bug** (17-RESEARCH Pitfall 1, A5): the AttributeError window is about 20 ms, and the slot-holder may finish inside 30 s with only one worker busy. D-15's three attempts and D-17's checkpoint at 17-04 cover it; the deterministic test is the proof either way.
- **`env -u` and the background server.** macOS `env` supports `-u`; if the Bash tool's background mode cannot be used, `nohup ... &` with the same redirection is equivalent. The server's PID is recorded so it is stopped deterministically.
- **Probe reconciliation.** REQ-same-slot-timeout-race-reproduced's four probe rows (adjacency, empty, ordering, concurrency) are authored above: three explicit truths and one backstop (adjacency -- whether a row is "the race" is read from the server records by a person as well as the check). 4 authored + 0 flagged = 4.
