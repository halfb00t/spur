<objective>
Turn the two reads of each table into the one table file the server loads, under D-08: diff the reads, give every
disagreement to the human, who settles it from the page, apply the settlement to both reads, and write the file only when
both pairs diff to zero and the file is complete. Nothing table-dependent can print before this plan's last task, because
the file does not exist until then.

Planner choice: the disagreement values go into an ignored file under `$MAIN/private/reads/` that the human opens beside the
page, not into the checkpoint message. The checkpoint message names locations and counts only, so no value can reach a
conversation log, STATE.md or a SUMMARY by way of the stop (D-01).

Purpose: the zero diff that REQ-tables-transcribed-twice requires, and the private file REQ-tables-private-file requires.
Output: `$MAIN/private/din5480-tables.json` (ignored, never committed) and two count-only logs.
</objective>
