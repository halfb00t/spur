<objective>
Build the developer-time tools the two reads run through, and run read 1 of DIN 5480-2 on the human's copy: a
`pdftotext -layout` parser that handles the copy's quirks on purpose (D-06), a canonical-model diff that reports
disagreements by table, row, column and page without printing a value (D-08, Pitfall 3), a join for the four parts of
read 2, an assemble step that writes the table file only when both pairs of reads agree, and `make` targets for each
(CLAUDE.md: reuse the command surface). The tools import the loader's models, so every read is written in one schema
(D-03) and checked by the same invariants the server applies.

Planner choices (Claude's Discretion):
- The tool is `scripts/din5480_tables_tool.py`, not research's `scripts/din5480_tables.py`, so `scripts.din5480_tables`
  and `spur.din5480_tables` cannot be confused in an import or a traceback.
- Completeness (`EXPECTED_COUNTS`: 721 size rows over 16 modules, 18 deviation letters by 9 columns, 8 classes by 9, 24
  tolerance rows, 21 column rows; research Table structure) is a transcription-time check (`check --complete`), not a
  load-time one, so the synthetic fixture stays small; the consequence the plan owns is that a real file missing a
  letter would read as "fit outside Table 7", which `assemble` prevents by running `--complete` before it writes.
- Read 1 runs here, in the plan that writes the parser, so the parser is proved on the copy before any read 2 starts;
  the read-2 plans (34-08..34-11) are forbidden to open its output.

Purpose: two reads that can be compared mechanically, and a table file that cannot exist until they agree.
Output: two scripts, five make targets, two light test files, read 1 in the ignored directory.
</objective>
