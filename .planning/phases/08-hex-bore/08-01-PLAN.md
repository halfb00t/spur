<objective>
Make the written requirement and the roadmap say what D-01 decided, before any code is written,
so the phase verifier checks Phase 8 against D-01 and not against the sentence D-01 superseded.

D-01 (locked, costly): a hex bore replaces the whole round/D-flat profile. `bore_d` and
`bore_flat` are ignored and warned about, never refused. The old REQ-hex-bore sentence and
ROADMAP Phase 8 SC2 made `bore_hex` plus `bore_flat` a 422; `bore_flat` defaults to 8.0, so that
422 would refuse every link that only adds `bore_hex`. The hex x keyway 422 stands and belongs to
Phase 9, which owns the keyway fields it names. This plan moves it there so it cannot fall out of
every requirement when REQ-hex-bore is marked complete.

Purpose: D-01 names this as the plan's first task. The later plans implement against the
amended text.
Output: REQUIREMENTS.md (REQ-hex-bore, REQ-keyway-bore, footer), ROADMAP.md (Phase 8 SC2,
Phase 9 SC2, Phase 12 SC1) and three STATE.md Roadmap Evolution lines, all in one commit after one
human confirmation.

Ordering note: this plan has no code layer to trace, so it carries no tracer task. D-01 orders it
first, and a locked user decision wins over the tracer-first default. The phase's tracer leads
08-02.
</objective>
