## Flagged Assumptions

- **The default `rho = 0.0` on `root_mode`** is this plan's call under D-16, which named the shipped `root_fillet`
  expression as "the natural reading". Taking it would make `root_mode` read `p.root_fillet` as rho, which D-07
  forbids in this phase; 0.0 is the legal sharp cutter and is ignored whenever nothing is requested (every present
  caller). Reversible: one default in one function, and Phase 19 passes its field's value either way.

  the space centreline, past the junction). D-11 asks for a named reason and a human checkpoint if any case inside
  the allowed box hits one; 18-03's sweep counts them and stops for the human if any appear, which is when a more
  specific name would be chosen.
