## Assumption delta (contribution: assumption-delta)

<assumption_delta_decision>
The detector fired on `pluralization` ("It is also the vocabulary Phase 24's selector is written in"): the relation's
condition gains a second consumer next phase.
- Noun now primary: the condition, `{field, op, value}`, built by `when()`. `enabled_when` is one key holding a list of
  conditions; Phase 24's selector options are to be written as `when()` conditions too, not as a second vocabulary.
- Decision: **promote**. `when()` is a module-level helper in `params.py`, not private to `_f()`; the JS `holds()` and
  the Python evaluators judge one condition at a time; the walk (23-02) validates every condition wherever it appears.
- Rationale: two vocabularies for one condition would state "hex wins" twice (the roadmap's own warning). The suggested
  invariant test is the 23-02 walk, which checks each condition through one function Phase 24 can call on its own key.
</assumption_delta_decision>
